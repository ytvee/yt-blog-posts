# Спланировать изображения

1. Прочитать `../../../knowledge/blog-format.md` и статью.
2. Выбирать изображения только там, где они помогают понять переход, механизм, эмоциональный поворот или длинный блок. Не ставить картинку после каждого заголовка.
4. Для каждой позиции вставить:

```html
<!-- IMAGE_SLOT id="img-01" role="hero" alt="..." association="..." -->
```

5. Заполнить `media-plan.md` по шаблону. В `MEDIA_CONTRACT` указать актуальный SHA статьи, `status: ready` и те же `id`, что в тексте.
6. По запросу пользователя добавить для выбранных слотов промпты: описать один ясный образ, композицию, настроение и запреты. Не копировать инструкции из временной папки `рисовальщик` и не делать её зависимостью.
7. После вставки заглушек пересчитать `readingTime`.

Cloudinary URL пользователь подставляет позднее. Не придумывать URL и не загружать изображения автоматически.
