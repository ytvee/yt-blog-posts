# Извлечь уроки из статьи

1. Прочитать утверждённую статью, `author-style.md`, `diversity-profile.md` и три последние записи `article-ledger.md`.
2. Зафиксировать:
   - тип начала;
   - композиционный каркас;
   - ритм и заметные переходы;
   - диалоги, вопросы, самоиронию и другие реально использованные приёмы;
   - тип финала;
   - Темы и авторские тезисы, вокруг которых построен материал.
3. Отличать устойчивый голос от разового решения под тему. Повторяющуюся черту переносить в `author-style.md` только при втором подтверждении либо по явному правилу «всегда/никогда».
4. Добавить в `article-ledger.md` запись со статусом `approved-awaiting-delivery`, SHA статьи, будущим URL и ссылкой на целевой файл. Вставить уникальный маркер `<!-- article:<english-slug>:<article-sha256> -->`.
5. Обновить `diversity-profile.md` одним-двумя ограничениями для следующей статьи. Не заставлять следующую статью отличаться выдуманным опытом.
6. Создать `work/articles/<slug>/learning-report.md` с блоком:

```html
<!-- LEARNING_CONTRACT
{"schemaVersion":1,"status":"ready","articleSha256":"...","ledgerSlug":"..."}
-->
```

Не изменять утверждённую статью.
