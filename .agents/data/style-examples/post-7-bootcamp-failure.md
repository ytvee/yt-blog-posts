# Reference Post 7

Quoted title:

- "Первый опыт. Большой факап."

## Post Mode

- postmortem post
- failure analysis

## Structural Signals

- names the failure directly
- gives context and numbers early
- identifies the mistaken assumption
- shows the consequence clearly
- ends with a changed next step, not with self-pity

## Voice Signals

- honest
- practical
- vulnerable without dramatics

## Reusable Techniques

- use the real numbers
- describe the wrong assumption plainly
- show what you would do differently
