# Формат статьи блога

## Фронтматтер

Каждый `current.md` и файл `<NNN>-after.md` начинается с единственного YAML-блока:

```yaml
---
title: "Название статьи"
date: "YYYY-MM-DD"
description: "Одно конкретное описание без рекламных обещаний."
tags: ["тег 1", "тег 2"]
readingTime: 7
ogImage: ""
published: false
---
```

Правила полей:

- `title` — непустая строка без точки в конце;
- `date` — календарная дата в формате ISO;
- `description` — самостоятельное описание содержания;
- `tags` — непустой JSON-совместимый массив строк в одну строку;
- `readingTime` — положительное целое число по формуле сайта: читаемые символы / 1500 + 0,2 минуты за изображение; округлять вверх при дробной части от 0,3, минимум 1;
- `ogImage` — URL либо пустая строка, пока обложка не готова;
- `published` — только `false` для рабочих черновиков.

Не добавлять другие поля до подключения репозитория `ytdev.me`.

## Основная разметка

- Не дублировать заголовок статьи как `# H1`: он уже находится во фронтматтере.
- Использовать `##` для основных разделов и `###` для подразделов.
- Добавлять оглавление, если статья длинная и содержит минимум три основных раздела.
- Для оглавления задавать явные якоря перед соответствующими заголовками:

```html
<a id="короткий-якорь"></a>
```

- Прямую речь и заметные цитаты оформлять через `>`.
- Разделитель из старых статей использовать только как осмысленную паузу:

```html
<div align="center">* * *</div>
```

Точное значение считать командой `node scripts/reading-time.mjs <article.md> --write` только после всех изменений.

## Медиаплейсхолдеры

Пока изображения или видео не выбраны, оставлять валидный HTML-комментарий:

```html
<!-- IMAGE_SLOT id="img-01" role="hero" ratio="16:9" alt="Краткое описание" association="Понятный образ" -->
```

`id` уникален и идёт по порядку. Допустимые `role`: `hero`, `section`, `evidence`, `diagram`, `video`. Для всех изображений внутри статьи — `hero`, `section`, `evidence` и `diagram` — обязателен `ratio="16:9"`. Для `video` ratio не обязателен. Атрибуты должны совпадать с `media-plan.md`. Не придумывать URL.

Квадратную OG-картинку `1:1` не вставлять в тело как `IMAGE_SLOT`. Её планировать отдельно в `media-plan.md`; готовый URL позднее записывать во фронтматтер `ogImage`.

Если готовое медиа уже передано, сохранять существующую разметку:

```markdown
![Описание](https://example.com/image.webp)
```

```html
<video controls preload="metadata" width="100%">
  <source src="https://example.com/video.mp4" type="video/mp4" />
</video>
```

## Рекомендуемый порядок

Порядок можно менять под материал:

1. Фронтматтер.
2. Горизонтальная hero-иллюстрация или плейсхолдер.
3. Короткий лид либо авторское вступление.
4. Оглавление для длинной статьи.
5. Основные разделы.
6. Естественное завершение без обязательного призыва к действию.

Лид, изображение и авторское вступление могут находиться до первого `##`, как в существующих статьях. Заголовок `#` в теле запрещён.
