# Политика поиска актуальных тем

## Разрешённая площадка

Темы для новых статей обнаруживать только по текущим обсуждениям на Hacker News — `news.ycombinator.com`. Допустимы официальный Hacker News API и поиск Algolia по данным Hacker News.

Не использовать для обнаружения тем новостные сайты, корпоративные блоги, Product Hunt, обычную поисковую выдачу, агрегаторы, рассылки и знания модели. Ссылку из обсуждения можно открыть после обнаружения темы только для проверки фактов: она не становится самостоятельным сигналом актуальности.

## Что считать актуальным

- По умолчанию анализировать последние 7 полных дней.
- Если найдено меньше пяти содержательных тем, расширить окно до 30 дней и явно это указать.
- Собирать только доступные фактические метрики: дату и время, ссылку, рейтинг или лайки, число комментариев или ответов, репосты и просмотры — если платформа их показывает.
- Не восстанавливать скрытые метрики по косвенным признакам и не использовать числа из поисковых сниппетов.
- Ранжировать обсуждения по баллам и числу комментариев, не складывая эти показатели в одно число.
- При итоговом отборе выше ставить темы, которые представлены несколькими независимыми публикациями или содержательными ветками Hacker News.
- Один вирусный пост не считать устойчивой темой без содержательного обсуждения или повторных независимых публикаций.

## Ограничения доступа

Если Hacker News и доступные интерфейсы его API не показывают прямые ссылки, даты, баллы или комментарии, остановить поиск и сообщить, какая часть данных недоступна. Не заменять Hacker News другим источником.

## Отчёт

Для каждой предложенной темы указывать:

- формулировку темы;
- прямые ссылки на обсуждения Hacker News;
- время среза и временное окно;
- видимые метрики без пересчёта;
- почему обсуждения относятся к одной теме;
- степень уверенности и пробелы данных;
- возможный авторский угол без выдумывания личного опыта.

Сохранять срез в `work/trends/YYYY-MM-DD.md`, если пользователь просит подготовить или зафиксировать подборку. Не делать по такому срезу выводов о поисковой частотности.
